# ماتشا وكّن الجمل 🐪

موقع طلب مسبق (استلام من الفرع) لـ **ماتشا وكّن الجمل**، وكل بياناته في ملف **قوقل شيت** واحد.

| الملف | وش هو |
|---|---|
| `index.html` + `app.js` | صفحة العملاء: الانترو، المنيو بالأقسام والسعرات، الكوب الاحتفالي (المناسبة + كرت الإهداء + طباعة صورة)، السلة، تتبع الطلب |
| `admin.html` | لوحة المحل (بكلمة مرور): الطلبات بالفرع والوقت، تغيير الحالة، تبليغ العميل، المتوفر، إيقاف الطلبات |
| `config.js` | رابط الربط مع قوقل شيت (`API_URL`) |
| `shared.js` / `style.css` | الأدوات والتصميم المشترك |
| `apps-script/Code.gs` | الكود اللي ينحط داخل قوقل شيت |
| `images/` | صور المنتجات والشعارات |

> إذا كان `API_URL` فاضي، يشتغل الموقع في **وضع العرض**: الطلبات تجريبية وتنحفظ في المتصفح بس، وكلمة مرور اللوحة `wk`.

## خطوات الربط (مرة وحدة)

### ١. ملف الشيت (على حساب wakuncoffee@gmail.com)
1. افتحي [sheets.new](https://sheets.new) وسمّي الملف «وكّن الجمل — إدارة».
2. **Extensions ← Apps Script**، امسحي الموجود، والصقي `apps-script/Code.gs` كامل، واحفظي.
3. اختاري الدالة **`setup`** واضغطي **Run** ← **Review permissions ← الحساب ← Advanced ← Go to … (unsafe) ← Allow**.
   (يطلب صلاحية قوقل درايف عشان يحفظ الصور المطلوب طباعتها في مجلد «وكّن الجمل — صور الأكواب الاحتفالية».)
4. بتلقين التبويبات جاهزة: المنيو، الإضافات، الحليب، الإعدادات، الطلبات.

### ٢. النشر كـ Web app
**Deploy ← New deployment ← Web app** · Execute as: `Me` · Who has access: `Anyone` ← **Deploy** وانسخي الرابط (ينتهي بـ `/exec`).

### ٣. ربط الموقع
```js
window.WK_CONFIG = { API_URL: "https://script.google.com/macros/s/XXXX/exec" };
```

### ٤. النشر على Cloudflare Pages
**Workers & Pages ← Create ← Pages ← Connect to Git** ← الريبو · Project name: `wakun` · Framework: `None` · Build: فاضي · Output: `/`.
لوحة المحل على `/admin.html`.

### ٥. قبل الإطلاق
- في **الإعدادات**: غيّري **كلمة مرور اللوحة**، وأضيفي اسم البنك واسم صاحب الحساب في **بيانات التحويل**، وروابط اللوكيشن للفروع (`اسم الفرع | الرابط`).
- **الفريدو** وأصناف القهوة السوداء ما وصلتنا سعراتها، أضيفوها في عمود السعرات لو تبون.
- جربي طلب من الجوال وتأكدي إنه يوصل للوحة ولتبويب «الطلبات».

> ⚠️ إذا عدّلتِ `Code.gs` بعدين: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** عشان يبقى نفس الرابط.

## إشعار واتساب لكل طلب جديد (Green API)
مع كل طلب جديد من الموقع، تنرسل رسالة واتساب لرقم البزنس فيها تفاصيل الطلب كاملة.

1. في **console.green-api.com** سوّي إنستانس واربطيه برقم الإرسال (رقم ثاني غير رقم البزنس) عن طريق QR.
2. في الشيت ← تبويب **الإعدادات**، عبّي الصفوف:
   - `واتساب: رقم استقبال الطلبات` ← رقم البزنس (مثال `966509116220`)
   - `Green API: idInstance` و `Green API: apiTokenInstance` و `Green API: apiUrl` ← من صفحة الإنستانس
   (الصفوف تنضاف لحالها بعد تحديث الكود؛ لو ما طلعت شغّلي `testNotify` مرة.)
3. في Apps Script شغّلي الدالة **`testNotify`** ووافقي على صلاحية الاتصال الخارجي، المفروض توصل رسالة تجربة لرقم البزنس.
4. **Deploy ← Manage deployments ← ✏️ ← New version ← Deploy**.

لإيقاف الرسائل: امسحي رقم الاستقبال من الإعدادات.

## الشيت: وش يعدّل المحل؟
| التبويب | الاستخدام |
|---|---|
| **المنيو** | `القسم` (ماتشا، قهوة باردة، قهوة حارة، احتفالي، حلويات، ماتشا باودر)، `السعر`، `السعرات`، `متوفر` نعم/لا، `الصورة`: اسم ملف من `images` أو رابط قوقل درايف، `الحليب`: اختيار بسعر / اختيار مجاني / بدون |
| **الإضافات** | طباعة صورة خاصة (15 ريال) وأي إضافة جديدة |
| **الحليب** | عادي مجانًا، خالي اللاكتوز +3، الشوفان +4، جوز الهند +4 |
| **الإعدادات** | الدوام (4 العصر – 12 الليل)، الإجازة، إيقاف الطلبات، البانر، الفروع، المناسبات، طرق الدفع، بيانات التحويل، كلمة المرور |
| **الطلبات** | تنضاف تلقائيًا، فيها الفرع ورابط الصورة المطلوب طباعتها |

## ملاحظات تقنية
- الأسعار تنحسب في الخادم من الشيت، فما أحد يقدر يتلاعب فيها من المتصفح.
- Apple Pay والشبكة تكون **عند الاستلام** (الدفع الإلكتروني داخل الموقع يحتاج بوابة دفع برسوم).
- اللوحة تتحدث كل 10 ثواني وتطلع صوت مع كل طلب جديد.
